## ✨ Key Features & Experience

- **Cinematic Hero Experience**: Immersive visual introduction with verified TNRERA registration badges, dual high-impact CTAs, and live metrics.
- **Editorial Brand Storytelling**: Explains the lifestyle advantage of living at the foothills of the Western Ghats with wide avenue blacktop roads and clear titles.
- **Forte Sports Town Showcase**: Spotlights the district's flagship sports complex featuring synthetic turf, floodlit box cricket, cricket practice nets, basketball, tennis, and skating rink.
- **Interactive Master Layout Visualizer**: Vector schematic layout allowing users to explore different plot zones (Boutique 2.5 Cents, Classic 3.5 Cents, Signature 5 Cents, Estate 7 Cents).
- **Interactive Plot & Villa Budget Estimator**: Dynamic sliders for cents to sq.ft conversion and villa construction cost projections.
- **Visual Property Gallery & Fullscreen Lightbox**: Editorial photo grid with category filters (Sports, Layout, Villas, Amenities) and keyboard navigation.
- **Location & Travel Time Matrix**: Interactive Google Maps embed with verified drive times to Theni New Bus Stand (15 mins), Theni District Court (3 mins), Medical College (22 mins), and schools.
- **High-Conversion Enquiry Form**: Client-side validated form with celebratory confetti, local lead persistence, and instant WhatsApp chat fallback.
- **WhatsApp Integration**: Floating button with pulse animations and pre-filled inquiry messages.
- **Brochure & Factsheet Generator**: Captures buyer leads and instantly provides the downloadable markdown factsheet.

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom luxury architectural palette (charcoal, obsidian, gold shimmer, ivory)
- **Icons**: Lucide Icons
- **Animation & Effects**: Canvas Confetti, subtle CSS animations, backdrop blur glassmorphism
- **SEO & Structured Data**: Schema.org JSON-LD `RealEstateListing`, OpenGraph tags, canonical tags

## 🚀 Quickstart & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Production Build
```bash
npm run build
```
Creates an optimized, tree-shaken static production bundle in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
